# GymSpot

Spor salonları için B2B SaaS: programa bağlı, kamerayla tekrar sayan ve formu anlık düzelten istasyon koçu. Telefon ve tablette çalışan PWA.

Proje **spec-driven** geliştirilir: önce `specs/` okunur. Claude Code için kurallar `CLAUDE.md` içindedir.

Başlangıç: `specs/00-vision.md` → `specs/10-roadmap.md` (görev sırası).
